# Projeto Connor

## Sobre o Projeto Connor

O projeto Connor é um projeto de Gestão Financeira com Agente de IA que ajudará a desenvolver melhor as finanças, saber onde esta indo e porque está indo. O projeto Connor tem como objetivo auxiliar e ajudar diariamente no que entra e sai  da sua conta bancária.
